# Publishing Studio — reference sealing
Programme > Mes formations > Préparer la publication, available only for draft non-pilot tracks. Server-side preflight displays actual ready revisions, total minutes of ready copies, last immutable reference, filter for unfinished activities, links to exact authoring revisions and human confirmation. The POST only seals a private complete release candidate. It does not modify official lessons, publish a track, open enrollment or change XP. The public catalogue keeps its prior proposed workload until actual activation. Existing pilot unaffected. New drafts can be edited after sealing without modifying the sealed version. Full historical contents are preserved backend; interface lists versions and links to current/latest sealed authoring revisions, not a full historical content browser. No automatic bulk approval. Follow-up: approved-release activation, dynamic learner studio and multi-track evaluations, then end-to-end acceptance before enrollment.
